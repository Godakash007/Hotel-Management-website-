## 🏨 Project Overview  
This Hotel-Management Website project uses **HTML, CSS, JavaScript and Bootstrap** to build a **responsive, interactive front-end** for a hotel booking system.  
It includes:  
- A **login page**  
- A **homepage** showcasing room types  
- A **reservation form**  
- A **contact page**  
The use of Bootstrap ensures a clean, intuitive layout and seamless mobile responsiveness.

---

## 📌 Key Features  
- Modern responsive design compatible with desktop, tablet and mobile devices.  
- Interactive UI components: navigation menu, image carousels, room filters.  
- Reservation UI: users can select rooms, dates and proceed to booking.  
- Contact form for users to submit inquiries.  
- Clean code structure in HTML/CSS/JavaScript for ease of maintenance.

---

## 🧰 Technologies Used  
- **HTML5** – markup structure of pages  
- **CSS3** – styling, layout and responsive design  
- **JavaScript** – client-side interactivity and form handling  
- **Bootstrap 5** – grid system, components and responsive utilities
